TonePush 0.8.0 is a new editor. Your pedal's presets sit in a sidebar beside three pages, Edit, Library and Pedal; the chain is drawn like a pedalboard with your footswitches and expression pedals along the bottom; and there is a light theme. The StompStation PRO gets its firmware updates from TonePush and saves on firmware 2.0.10, and a long list of fixes makes backups, saving and switching presets safer on every pedal.

## New

- **A new editor.** The pedal's presets stay in a sidebar on every page, in the pedal's own banks. **Edit** shows the chain the way the pedal runs it, with lanes for parallel paths, the selected block's knobs, and your footswitches and expression pedals along the bottom. The model browser, footswitch assignments and snapshot table open in place of the knobs. **Library** is a table of your tones and setlists, compared with what is on the pedal. **Pedal** holds backups, impulse responses, NAM models and settings. The status bar and floating windows are gone. Text and numbers use Inter throughout. By @crmne.
- **A light theme.** TonePush follows your system's light or dark setting. By @crmne.
- **The connect page finds your pedal by itself.** Plug it in, or quit another editor that held it, and TonePush picks it up. The page also says whether this computer can reach USB pedals and whether HX Edit's model data is in place. By @crmne.
- **StompStation PRO firmware updates.** Start the pedal in update mode (once the Sonulab logo shows, hold UPD until the screen says Update Mode) and install Sonulab's `.zip` from the Pedal page, or with `tonepush pro firmware-update`. TonePush checks that the file is pedal firmware of the version you expect and that you have a fresh backup, confirms every batch it sends, and never restarts the pedal for you: it tells you when to. Tested with `tonepush pro firmware-update` by updating a pedal from 1.5.12 to 2.0.10, then 2.2.6, then back to 2.0.10, keeping every preset, IR and NAM model each time; the Pedal page runs the same steps. By @crmne.
- **StompStation PRO on firmware 2.0.10.** Saving, renaming, moving, clearing, importing presets, mono and stereo IRs and NAM models, global settings and restore were each checked on a pedal running 2.0.10 by reading the result back. NAM models cannot be reordered on 2.0.10, because that firmware keeps playing the old model until it restarts. By @crmne.
- **Firmware TonePush does not know yet opens read only, with presets live.** Browsing, export and backups work, and you can still pick presets and turn knobs; only writes to the pedal's memory wait. That covers 2.2.6 for now (see Known limitations). By @crmne.
- **The new filled app icon** stays recognisable at taskbar sizes. By @crmne.

## Fixed

- **A backup never deletes a folder.** Backing up an HX or a StompStation PRO into a folder that already held other files replaced it and deleted its contents. A backup now goes only into a new folder, an empty one, or an earlier backup. By @crmne.
- **A StompStation PRO backup is checked in full.** Only the start and end of each slot were compared, so a preset saved over itself under the same name went unnoticed: saving could unlock against an old backup, and a restore could skip that preset. Every preset and IR is now compared byte for byte, and each NAM model by its checksum. Automatic backups no longer replace the one taken earlier that day. By @crmne.
- **Helix backups cover every setlist**, not just the first, and `tonepush save` saves into the setlist that is loaded. By @crmne.
- **The editor follows presets and snapshots picked on the pedal.** Before, changing preset on the HX itself left the editor showing the old one, so Undo or Save could write it over the new one. By @crmne.
- **Switching presets asks before throwing away unsaved changes**, from every place that can switch: rows, arrow keys, menus, the preview's Load, a failed "Save, then load", and a cloud audition. By @crmne.
- **Saves and uploads are confirmed by what the pedal reads back.** A tempo or snapshot name that never landed counted as written, and an impulse response re-uploaded under the same name was taken as done before it was. By @crmne.
- **Dropping several WAV files gives each its own impulse-response slot**, instead of all of them overwriting one. By @crmne.
- **Moving a controller's travel no longer disconnects the pedal**, and tempos outside what the pedal accepts are refused with a message. By @crmne.
- **Pasting a block pastes the block you copied**, in this preset or another. By @crmne.
- **Closing the window waits for a transfer to finish**, instead of cutting it off and leaving the pedal on "transferring data". By @crmne.
- **`.hlx` import keeps the cab of an Amp+Cab**, and blocks keep the positions the file gives them. By @crmne.
- **Saved setlists are safer.** One unreadable file (such as a `._` file from macOS) no longer hides every setlist, and renaming an old setlist can no longer overwrite another one. By @crmne.
- **Cloud downloads are checked against the hash tonepush.rocks publishes**, so a Wi-Fi sign-in page can no longer land in your library, and a stalled download gives up instead of blocking the next one. By @crmne.
- **NAM model uploads to a StompStation PRO are confirmed correctly.** The pedal gzips a model again when it is read back, with its own header, so a correct upload was reported as failed; uploads are now checked by the model they contain. An upload under a name another slot already uses, which the pedal silently ignores, is refused with a message. By @crmne.
- **24-bit WAV impulse responses saved in the "extensible" format** (as ffmpeg and SoX write them) import. By @crmne.
- **Smaller fixes:** a preset address ending in an accented letter no longer crashes the CLI; snapshot names with control characters are refused instead of corrupting the preset; the CLI numbers blocks from 1 everywhere; knob columns sort negative values correctly; `install.sh` runs from any folder, quotes paths with spaces and leaves Homebrew's links alone on uninstall. By @crmne.

## Known limitations

- The StompStation PRO board shows the fixed twelve-block chain of firmware 1.5.12. On 2.x its parameters are all editable, but the new routing (parallel paths, free positions, the new effects as blocks) is not drawn yet.
- **Firmware 2.2.6 is read only.** Over USB it stops answering after a stretch of large replies, so a complete backup cannot be relied on, and saving waits for that. The cause looks like 2.2.6's new USB audio: once the computer has used the pedal as a sound card, the pedal's USB controller interrupts it constantly while TonePush reads. VoidX Control's slower, smaller requests seem to avoid it. If you need saving now, TonePush can put 2.0.10 back on the pedal (Pedal page, or `tonepush pro firmware-update`), keeping your presets, IRs and NAM models.
- An HX Effects backup can still time out while reading the pedal's settings (#9), and an HX Stomp on firmware 3.80 that stays on "transferring data" (#5) is still being investigated.
- 0.6.1 and earlier have no Update button, so moving to 0.8.0 from them is a manual download.
