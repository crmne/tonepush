TonePush 0.11.0 gets more pedals connected and importing. A StompStation PRO that sends text TonePush cannot read now opens instead of failing to connect, `.hlx` import works on an HX Effects, and a new `batch` command runs a whole preset build over one connection, in seconds rather than minutes. Windows now ships as a signed `.msi` only.

## New

- **`tonepush batch` runs many commands over one connection.** Give it a file of commands, or pipe them in. The whole file is read first, so a typo stops it before the pedal is touched; a line that fails is reported and the rest still run; `sleep <ms>` gives the pedal time where it needs it. In @AC6y86's measurements on an HX Effects, a 100-command preset build went from about 12 minutes to about 11 seconds. See [the CLI guide](https://docs.tonepush.rocks/using-the-cli/). By @crmne, from the design and measurements of @AC6y86 (#8).
- **Windows releases are signed**, and Windows ships as the `.msi` only. By @crmne in #45 and #70.

## Fixed

- **A StompStation PRO opens when it sends a byte that is not valid text.** It used to stop at "VoidX frame was not UTF-8". The character shows as `�` and the pedal connects. By @crmne; thanks @christoph-krionx (#74).
- **`.hlx` import works on an HX Effects.** Every menu in a file was sent as a number the pedal refused, so all imports failed with error -3. By @crmne; thanks @robbuckles, who found the cause and tested it on a pedal (#44).
- **A failed preset write says what differed**, so a pedal that reports a failure can show which field it kept for itself. By @crmne; thanks @robbuckles (#44).
- **`install.sh` replaces a udev rule from before StompStation PRO support**, which left the pedal's serial port closed to the editor. By @crmne.
- **An HX Effects backup no longer times out** reading the pedal's settings. Fixed by #31 in 0.10.0 and now confirmed on an HX Effects by @robbuckles (#9).

## Known limitations

- The Windows setup program (`-setup.exe`) is gone. Installs from 0.9.1 on move to the `.msi` through their own update, keeping their folder, desktop shortcut and settings. **A copy still on 0.9.0 must run the `.msi` once by hand.**
- The StompStation PRO fix was tested in unit tests and on firmware 2.2.6, not on 2.2.7, where it was reported. Writes are allowed across 2.2.x, but TonePush has been verified on 2.2.6 only.
- Restoring a preset on an HX Effects can report a failure although it landed (#44).
- An HX Stomp on firmware 3.80 that disconnects after a few seconds (#5), and a StompStation PRO the editor cannot open while the command line finds it (#34), are still being investigated. The error on the connect page tells us what to fix.
- `batch` and the import fix have not been run on hardware by the maintainer; the import fix was tested on an HX Effects by its reporter.
- Helix LT and Helix Rack have not been tested on real hardware.
