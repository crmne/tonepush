TonePush 0.12.2 runs on a Windows machine that does not have the Visual C++ runtime installed, so the installer, the zip and winget need nothing else. It also keeps a preset it cannot read from stopping a backup, reads the HX Effects presets that caused that, lets you pick a value from a control's list again, and keeps a Helix Floor's display working after a session.

## Fixed

- **TonePush starts on a clean Windows machine.** On a computer without the Visual C++ runtime, both programs stopped at once because a DLL was missing. The runtime is now inside the executables, on x64 and ARM, in the installer and the zip. By @crmne.
- **A preset TonePush cannot read no longer stops a backup.** One such preset ended the read and dropped the pedal on every connect. A backup now keeps its bytes as the pedal stores them and lists the slot in `unreadable-presets.json`, and a restore leaves that slot as the pedal has it. By @crmne.
- **HX Effects presets with snapshots that leave the tempo alone can be read.** The pedal writes 0 for that tempo, which made the whole preset unreadable and with it every backup of the pedal. By @AC6y86 in #83.
- **A control with named choices opens its list on a click.** A setting such as a compressor's Ratio opened its list and closed it again in the same click, so no choice could be picked. By @AC6y86 in #88.
- **A Helix Floor's display keeps up after a session with TonePush.** When a session ended, the Floor kept playing but its display froze at the next preset change until it was switched off and on. TonePush now closes the session the way HX Edit does when it quits. Measured on a Helix Floor at 3.80; other pedals end their sessions as before. By @Jazzpirate in #102.
- **The download page offers the Flatpak bundle, and a bundle's update message is right.** A bundle has no remote, so TonePush now says to install the next bundle instead of showing a `flatpak update` command that cannot work. By @crmne.

## Known limitations

- The Windows ARM build was checked by the DLLs it imports, not run: no ARM Windows machine was available.
- An HX Stomp on firmware 3.80 that disconnects after a few seconds (#5), and a StompStation PRO the editor cannot open while the command line finds it (#34), are still being investigated.
- Helix LT and Helix Rack have not been tested on real hardware.
