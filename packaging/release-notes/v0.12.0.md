TonePush 0.12.0 gets out of your way when you plug in. The backup TonePush takes as a pedal connects can be skipped when you want to play right away, it is not taken again the same day while the pedal still holds the same presets, and impulse responses already backed up are not read again. An HX Stomp with dozens of IRs no longer disconnects and reconnects in a loop while it is backed up. Updates now install by themselves at the next start, and Linux gets a Flatpak bundle and a Fedora COPR.

## New

- **Skip the backup when you need the pedal now.** While TonePush backs up a pedal that just connected, Skip sits beside the progress. On an HX it stops the backup and keeps the last one; on a StompStation PRO it stops the check that unlocks saving, so you can play and edit straight away and saving waits for a backup. Either way the next connection tries again, and closing the window skips it too. By @crmne.
- **A pedal is backed up once a day, not on every connect.** If the backup taken earlier today still matches the pedal (same presets in every setlist, same impulse responses), connecting again takes a moment instead of reading the whole pedal. Every save keeps that backup current, and a change made on the pedal itself or in HX Edit is noticed and backed up. By @crmne.
- **Impulse responses are backed up once.** An IR whose name and checksum match the last backup is copied from it instead of read from the pedal again, so a pedal with many IRs backs up much faster after the first time. By @crmne.
- **Updates install by themselves.** A new release on the same major version downloads in the background and installs the next time TonePush starts, before the window opens. With Install updates automatically turned off in Settings, or for a new major version, TonePush waits for you to choose Restart to update. A copy installed by a package manager shows the command that updates it. By @crmne.
- **A Flatpak bundle and a Fedora COPR for Linux.** Each release now ships `rocks.tonepush.TonePush` as a Flatpak bundle, and `sudo dnf copr enable paolino/tonepush` installs and updates TonePush on Fedora. The [download page](https://docs.tonepush.rocks/download/) has the details, including the udev rule a Flatpak cannot install for you. By @crmne.

## Fixed

- **An HX Stomp with many impulse responses stays connected while it is backed up.** Reading dozens of IRs left two of the pedal's three channels quiet for so long that it stopped answering them; the session dropped, and every reconnect started the backup again. By @crmne; thanks @noursbleu (#79).

## Known limitations

- None of this was tried on a pedal by the maintainer: it was tested against simulated HX and StompStation PRO connections. The #79 fix follows from the report and the code; @noursbleu's pedal will tell.
- On a StompStation PRO the check that unlocks saving still reads every slot, because the pedal has no checksum to compare instead. Skip is the way around it for now.
- An HX Stomp on firmware 3.80 that disconnects after a few seconds (#5), and a StompStation PRO the editor cannot open while the command line finds it (#34), are still being investigated. #5 may be the same backup problem as #79.
- Helix LT and Helix Rack have not been tested on real hardware.
