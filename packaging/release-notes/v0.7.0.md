TonePush 0.7.0 updates itself: the Mac app and the Linux and Windows downloads fetch a new release, check its signature and install it when you restart. Parameters chosen from a menu can be changed, the HX Effects gets its own preset labels and can read its stored presets, and text is drawn the way the rest of your desktop draws it.

## New

- **Updates install from inside the editor.** When a newer release is out, an **Update** button appears beside the version in the status line. TonePush downloads the release, checks it against the signed checksums, and offers **Restart to update**. If the new version does not start, the previous one comes back. This works for the Mac app and the Linux and Windows downloads; Homebrew, AUR, `.deb` and `.rpm` installs keep updating through their package manager, and hovering the version says which one. TonePush now checks GitHub for a new release once a day instead of at every launch. By @crmne.
- **Release checksums are signed.** Every release's `checksums.txt` comes with a signature the updater verifies before installing anything. By @crmne.
- **Text looks like the rest of your desktop.** On Linux TonePush follows the desktop's font hinting setting, and in the dark theme text has the same weight as GTK apps beside it. Tone and setlist names in scripts Inter lacks, such as Chinese, Japanese, Arabic, Hebrew or Hindi, are drawn with your system's fonts instead of boxes. By @crmne.
- **HX Effects preset labels run 01A to 32D.** Presets, selection, renaming, saving and backups use the HX Effects' four presets to a bank, so `27A` in TonePush is `27A` on the pedal. The HX Stomp keeps its three. By @iibaranov-IG in #12; thanks @fruzz-urban for the report (#9).

## Fixed

- **Menu parameters can be changed.** Setting a parameter chosen from a menu, such as a compressor's Ratio or a phaser's Stages, was refused by the pedal with `error -3`, in both the editor and `tonepush set`. By @crmne; thanks @AC6y86 for the diagnosis and fix (#7).
- **An HX Effects can read and back up its stored presets.** Untouched factory presets, snapshots whose names were never typed, and controller assignments under a source the HX Stomp does not use no longer stop a backup at the first preset. By @crmne with @fruzz-urban's fix, tested on all 119 presets of their unit (#9).

## Known limitations

- 0.6.1 and earlier have no Update button, so moving to 0.7.0 is one last manual download.
- An HX Effects backup can still time out while reading the pedal's settings, after all presets are read (#9).
- Helix Floor, Rack and LT and the HX Stomp XL are still labelled with three presets to a bank.
- An HX Stomp on firmware 3.80 that stays on "transferring data" (#5) is still being investigated.
